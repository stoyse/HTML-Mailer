
# HTMLMailer

**HTMLMailer** is a lightweight desktop application for sending styled HTML emails via SMTP, designed for macOS and Windows. It provides a simple GUI to manage email credentials, compose messages, and customize HTML templates securely.


## Features

- 📧 Send rich HTML emails using a customizable template

- 🔒 Encrypt and store credentials securely (Fernet encryption)

- ⚙️ Settings window to configure sender email and password

- 💾 Saves HTML templates for reuse

- 🧰 Simple, intuitive Tkinter GUI

- 🖥️ Built for distribution as .app (macOS) and .exe (Windows) with all dependencies bundled
## Installation

### macOS

1. Download the .app file or zipped archive.

2. If downloaded as a ZIP, unzip it:
```bash
unzip HTMLMailer.zip
```

3. Double-click HTMLMailer.app to launch.

### Windows

1. Download and run the .exe installer or bundled app.

2. The application will open directly without needing Python installed.
